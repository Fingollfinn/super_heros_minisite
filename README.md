# Site web super héros

Mini-site web sur le thème des super-héros, réalisé en binôme pour s'entraîner à HTML/CSS/JS et aux bases de Git.

## Description

Ce projet est réalisé dans le cadre de la formation BUT SD (Science des Données) des auteurs. Il a un double objectif :

- s'entraîner aux langages web **HTML**, **CSS** et **JavaScript** ;
- découvrir le **travail collaboratif avec Git** : versionnage, commits partagés, synchronisation avec un dépôt distant.

Le travail est mené en coopération du début à la fin. Il s'agit d'un premier essai de collaboration, donc l'utilisation de Git reste volontairement basique : **pas de branches**, tout le monde travaille sur `main`.

## Contenu du dépôt

| Fichier | Rôle |
|---|---|
| `index.html` | Page d'accueil |
| `heroes.html` | Page présentant les héros |
| `style.css` | Feuille de style commune |

## Utilisation

Cloner le dépôt, puis ouvrir `index.html` dans un navigateur :

```bash
git clone https://github.com/Fingollfinn/super_heros_minisite.git
cd super_heros_minisite
```
